═══════════════════════════════════════════════════════════════════

PROBLEM

Previous fixes using flexbox and CSS Grid didn't work. Layout still 
broken with all elements squished at bottom. The debug colors proved
the grid was working but the container wasn't filling the viewport.

═══════════════════════════════════════════════════════════════════

ROOT CAUSE

Flexbox (flex: 1) was NOT making main-content fill the available space.
Something in the flex calculation was broken, causing main-content to
not expand to fill the viewport.

═══════════════════════════════════════════════════════════════════

THE NUCLEAR FIX: ABSOLUTE POSITIONING

Completely abandoned flexbox for the main layout. Now using absolute
positioning which FORCES elements to fill exact pixel dimensions.

**BEFORE** (Broken Flexbox):
```css
body {
    display: flex;  /* Rely on flex layout */
}
.sidebar {
    width: 280px;
}
.main-content {
    flex: 1;  /* This wasn't working! */
}
```

**AFTER** (Absolute Positioning):
```css
body {
    position: relative;  /* Parent for absolute children */
}
.sidebar {
    position: absolute;
    left: 0;
    top: 0;
    bottom: 0;
    width: 280px;
}
.main-content {
    position: absolute;
    left: 280px;  /* Start after sidebar */
    right: 0;     /* Fill to right edge */
    top: 0;       /* Fill from top */
    bottom: 0;    /* Fill to bottom */
}
```

═══════════════════════════════════════════════════════════════════

WHY THIS WILL WORK

Absolute positioning with explicit coordinates FORCES elements to be
exactly where you tell them:

- Sidebar: LOCKED to left edge, full height
- Main-content: LOCKED to fill from 280px to right edge, full height

There's NO calculation, NO flexbox ambiguity, NO "why isn't it working".
It's explicit pixel coordinates that the browser MUST honor.

Grid inside main-content still works perfectly:
- grid-template-rows: auto 1fr auto
- Header takes natural height
- Chat fills remaining space
- Input takes natural height

WHY ABSOLUTE POSITIONING IS BETTER HERE

Advantages:
✅ Explicit, predictable positioning
✅ No flex calculation ambiguity
✅ Works in ALL browsers consistently
✅ Can't be affected by content size
✅ Forces exact dimensions

Disadvantages:
❌ Less flexible for responsive design
❌ Need to handle mobile separately
❌ Can't easily add more columns

But for a fixed 2-column layout (sidebar + main), absolute 
positioning is actually IDEAL. It's what many professional 
dashboards use (Gmail, Slack, Discord, etc.)
