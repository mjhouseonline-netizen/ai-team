✅ PROMO CODE BUG FIXED - UNLIMITED USES NOW WORK!

═══════════════════════════════════════════

THE BUG:
Your create_promo_codes() function was hardcoded to set max_uses = 1
This meant EVERY generated code could only be used ONCE!

Result: After first redemption → "Maximum uses reached" ❌

═══════════════════════════════════════════

THE FIX:

1. Changed max_uses from 1 to -1 (unlimited)
2. Added is_active and single_use fields
3. Fixed validation to skip max_uses check when = -1

BEFORE (Line 2780-2781):
```python
INSERT INTO promo_codes (code, tier, max_uses)
VALUES (?, ?, 1)  # ← HARDCODED TO 1!
```

AFTER (Line 2780-2783):
```python
max_uses = -1  # Default: unlimited uses

INSERT INTO promo_codes (code, tier, max_uses, is_active, single_use)
VALUES (?, ?, ?, 1, 0)  # ← Now uses -1 (unlimited)
```

═══════════════════════════════════════════

VALIDATION FIX:

BEFORE (Line 2825-2826):
```python
if not single_use and times_used >= max_uses:
    return False, "This promo code has reached its maximum uses"
```

AFTER:
```python
if not single_use and max_uses != -1 and times_used >= max_uses:
    return False, "This promo code has reached its maximum uses"
    #              ↑ Skip check if max_uses = -1 (unlimited)
```
