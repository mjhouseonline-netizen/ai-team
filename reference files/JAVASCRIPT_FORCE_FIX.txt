THIS IS THE FINAL FIX

If CSS (even with !important and inline styles) isn't working, then
something must be overriding it with JavaScript or applying styles
AFTER our inline styles load.

So now we're using JAVASCRIPT to FORCE the CSS properties directly
onto the elements, overriding EVERYTHING.

═══════════════════════════════════════════════════════════════════

HOW IT WORKS

A JavaScript function runs MULTIPLE TIMES:
1. Immediately when script loads
2. On DOMContentLoaded event
3. After 100ms delay
4. After 500ms delay
5. After 1000ms delay

Each time it:
- Finds the main-content, header, chat, input elements
- Uses `.style.cssText` to SET CSS DIRECTLY
- Forces visibility, opacity, display, position, colors

This CANNOT be overridden by stylesheets because JavaScript-set
inline styles have maximum specificity.

═══════════════════════════════════════════════════════════════════

THE CODE

```javascript
function forceGuestModeVisible() {
    const mainContent = document.querySelector('.main-content');
    const header = document.querySelector('.header');
    const chat = document.querySelector('.chat-container');
    const input = document.querySelector('.input-container');
    
    if (mainContent) {
        mainContent.style.cssText = 'position: absolute !important; ...';
    }
    // Same for header, chat, input
}

// Run immediately
forceGuestModeVisible();

// Run on DOM load
document.addEventListener('DOMContentLoaded', forceGuestModeVisible);

// Run after delays to override other scripts
setTimeout(forceGuestModeVisible, 100);
setTimeout(forceGuestModeVisible, 500);
setTimeout(forceGuestModeVisible, 1000);
```

2. Runs multiple times to catch any timing issues
3. Sets EVERY property needed (position, size, color, visibility)
4. Uses !important in JS-set styles
5. Console logs confirm execution
