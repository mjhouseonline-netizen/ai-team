FIX #1: CHAT LAYOUT - WHITE BACKGROUND

**ISSUE**
User reported: "the chat is in the left it should be in the white box"

**ROOT CAUSE**
The main-content div didn't have an explicit white background color set,
so it may have been transparent or inheriting a different color.

**FIX APPLIED**
Added to main-content CSS (line ~252):
```css
.main-content {
    ...existing properties...
    background: var(--bg-main); /* White background */
}
```

This ensures the main chat area has a white background, making it
visually distinct from the dark sidebar.
