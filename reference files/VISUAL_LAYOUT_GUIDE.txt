USER FLOW:

SCENARIO 1: View Past Chats

1. User clicks "📜 History" button
2. Dropdown opens showing all conversations
3. User sees chat from yesterday: "🌙 Market research for Q1"
4. Clicks on it
5. Chat loads with all previous messages
6. User can continue the conversation
7. Messages auto-save to that conversation

SCENARIO 2: Start New Chat

1. User clicks "📜 History"
2. Clicks "✨ New Chat" at top
3. Chat clears
4. Fresh conversation starts
5. First message creates new conversation
6. Auto-title generated from first message

SCENARIO 3: Delete Old Chat

1. User clicks "📜 History"
2. Hovers over old conversation
3. Delete button (🗑️) appears
4. Clicks delete
5. Confirms deletion
6. Chat removed from list

SCENARIO 4: Share Agent Link

1. User scrolls sidebar to "🔗 Shareable Links"
2. Sees Luna's link: ai-team.skillsoul.store/agent/Luna
3. Clicks "Copy" button
4. Link copied to clipboard
5. Pastes in email/Twitter/website
6. Visitors click link → Opens Luna directly
