## 🔧 Common Issues & Solutions

### **Issue: Voice input not working**
- **Solution:** Use Chrome or Edge browser
- Check microphone permissions
- Click the 🎤 button before speaking

### **Issue: Text-to-speech not working**
- **Solution:** Make sure volume is on
- Try different browsers
- Check 🎙️ Voice Settings

### **Issue: Images not generating**
- **Solution:** Try a simpler prompt
- Wait 5-10 seconds
- Check your message limit

### **Issue: Download not working**
- **Solution:** Check browser downloads folder
- Try right-click → Save As
- Check popup blocker settings

### **Issue: Stats showing dashes (- / - / -)**
- **Solution:** This is a known issue being fixed
- Platform still works normally
