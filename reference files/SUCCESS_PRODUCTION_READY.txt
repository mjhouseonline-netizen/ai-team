THE ROOT CAUSE (For Reference)

The issue was that main-content was positioned at left:0 instead of
left:280px, so it was BEHIND the sidebar all along!

Using `.style.cssText` was creating incorrect CSS shorthand (`inset`)
with wrong values.

The fix was setting each CSS property individually via JavaScript:
```javascript
mainContent.style.position = 'absolute';
mainContent.style.left = '280px';  // ← CRITICAL!
mainContent.style.right = '0';
// etc...
```
