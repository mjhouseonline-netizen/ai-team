FIX #1: CUSTOM AGENT DATABASE ERROR

PROBLEM:
Error creating agent: table custom_agents has no column named role

ROOT CAUSE:
- Database table has 'description' column
- Backend function was looking for 'role' column
- Mismatch between schema and function

SOLUTION:
Updated create_custom_agent() function in web_app_auth.py:

BEFORE:
```python
role = data.get('role')
if not name or not role:
    return jsonify({'error': 'Name and role are required'}), 400

INSERT INTO custom_agents (user_id, name, role, emoji, personality, system_prompt)
VALUES (?, ?, ?, ?, ?, ?)
```

AFTER:
```python
description = data.get('role') or data.get('description')  # Accept both
if not name or not description:
    return jsonify({'error': 'Name and description are required'}), 400

INSERT INTO custom_agents (user_id, name, description, emoji, personality, system_prompt)
VALUES (?, ?, ?, ?, ?, ?)
```

CHANGES:
✅ Changed 'role' variable to 'description'
✅ Accepts both 'role' and 'description' from frontend for compatibility
✅ Uses 'description' column in INSERT statement
✅ Removed duplicate code lines
✅ Fixed return statement to use 'description'

RESULT:
✅ Custom agents now save successfully

HTML Changes (dashboard.html):

```html
<!-- AFTER -->

    <button onclick="buildPrompt()">Generate Prompt</button>
    <button onclick="copyPrompt()">📋 Copy Prompt</button>
    <button onclick="usePrompt()">Use This Prompt</button>
</div>
```

JavaScript Function Added:
```javascript
function copyPrompt() {
    const prompt = document.getElementById('promptOutput').value;
    if (!prompt) {
        alert('Please generate a prompt first!');
        return;
    }
    
    // Copy to clipboard
    navigator.clipboard.writeText(prompt).then(() => {
        showNotification('✅ Prompt copied to clipboard!');
    }).catch(err => {
        // Fallback method for older browsers
        const textarea = document.getElementById('promptOutput');
        textarea.select();
        document.execCommand('copy');
        showNotification('✅ Prompt copied to clipboard!');
    });
}
```

FEATURES:
✅ "📋 Copy Prompt" button added
✅ Copies generated prompt to clipboard
✅ Shows success notification
✅ Has fallback for older browsers
✅ Works alongside "Use This Prompt" button

HOW IT WORKS:
1. User clicks "Generate Prompt"
2. Structured prompt appears
3. User has THREE options:
   a) "Generate Prompt" - Generate new prompt
   b) "📋 Copy Prompt" - Copy to clipboard (NEW!)
   c) "Use This Prompt" - Copy to message input

RESULT:
✅ Prompts are now copyable
✅ Easy one-click copy
✅ Success notification appears
✅ Can paste anywhere (notes, docs, etc.)
