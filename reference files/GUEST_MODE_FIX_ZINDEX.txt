WHAT I FIXED

**Issue: Z-Index and Display Properties Missing**

The main-content div and its children (header, chat-container, 
input-container) weren't explicitly set to display for guest mode.
They might have been hidden or positioned incorrectly.

**Changes Made:**

1. **main-content** (line ~257)
   - Added `z-index: 1` to base rule
   - Added `z-index: 1 !important` to guest-mode rule
   - Added `background: var(--bg-main) !important` to ensure visibility

2. **header, chat-container, input-container** (lines ~280-312)
   - Added `display: flex !important` to header
   - Added `display: block !important` to chat-container and input-container
   - Added `position: relative !important` to all three
   - Added `z-index: 2 !important` to all three (above main-content)

This ensures these elements are:
- Explicitly visible (display property)
- Positioned correctly (position: relative)
- Above any potential overlays (z-index)
