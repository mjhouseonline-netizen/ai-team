## 🐛 **Troubleshooting:**

### **Download Button Doesn't Appear:**

**Issue:** AI didn't format code properly  
**Solution:** Ask: "Can you provide the complete HTML code in a code block?"

### **File Won't Open:**

**Issue:** File type association  
**Solution:** 
1. Right-click file
2. "Open with" → Choose browser
3. Or rename to ensure `.html` extension

### **Website Looks Broken:**

**Issue:** Missing external resources  
**Solution:** Ask AI to use only embedded styles/scripts, no external links

### **Want to Make Changes:**

**Issue:** Need to edit content  
**Solution:** Open file in text editor, find text you want to change, save
