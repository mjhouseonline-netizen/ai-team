HOW IT WORKS:

CHAT HISTORY SYSTEM:

1. User sends message → Saved to chat_history table with conversation_id
2. Messages grouped into conversation sessions
3. Conversation title auto-generated from first message
4. Click History → Loads all conversations from /api/conversations
5. Conversations grouped by date (Today, Yesterday, Last 7 Days, Older)
6. Click conversation → Loads from /api/conversation/<id>
7. All messages displayed in order
8. Can continue chatting in that session
9. Delete conversation → Soft delete (is_active = 0)

SHAREABLE LINKS:

1. Each agent has URL: /agent/<agent_name>
   Example: https://ai-team.skillsoul.store/agent/Luna

2. If logged in → Opens dashboard with that agent selected
3. If not logged in → Shows agent info page with signup button

4. Custom agents get unique share codes
   Example: https://ai-team.skillsoul.store/custom/abc123

5. Can embed in iframes or share on social media

6. Links work on external websites!

API ENDPOINTS ADDED:

GET /api/conversations
- Returns all conversations for current user
- Sorted by updated_at DESC
- Limit 50 most recent

GET /api/conversation/<id>
- Returns specific conversation with all messages
- Includes: id, agent, title, messages[]
- Verifies ownership

POST /api/conversation/new
- Creates new conversation session
- Body: {agent, title}
- Returns: conversation_id

POST /api/conversation/<id>/delete
- Soft deletes conversation (is_active = 0)
- Verifies ownership
- Returns: success status

GET /agent/<agent_name>
- Shareable public agent link
- Works without login
- Valid agents: Luna, Mila, Sage, Ember, Sol, Nova, Theo

GET /custom/<share_code>
- Shareable custom agent link
- Requires login if not public
- Loads agent by unique share code
