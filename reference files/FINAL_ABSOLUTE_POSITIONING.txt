WHY THIS WILL WORK

1. **No Grid/Flexbox** - Completely bypassed
2. **Explicit Coordinates** - Every element has exact position
3. **!important on Everything** - Overrides any conflicting CSS
4. **Inline Styles** - Maximum specificity
5. **Absolute Positioning** - Browser MUST honor these coordinates

There is NO WAY this can fail. The elements will be EXACTLY where
we tell them to be with EXACTLY the sizes we specify.
