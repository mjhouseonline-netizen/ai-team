THE PROBLEM - FINALLY IDENTIFIED

Looking at your browser inspector screenshot, I saw the main-content div had:

```css
style="inset: 0px 0px 280px !important; ..."
```

This means:
- top: 0px ✅
- right: 0px ✅  
- bottom: 280px ❌ WRONG!
- left: 0px ❌ WRONG!

**The sidebar is 280px wide and positioned at left: 0**
**The main-content was ALSO at left: 0**

**They were overlapping! The main-content was BEHIND the sidebar!**

That's why you saw only white - the content was there, but completely
hidden behind the 280px-wide sidebar.

═══════════════════════════════════════════════════════════════════

WHY CSSTEXT FAILED

Using `.style.cssText` with inline styles was being parsed incorrectly
by the browser. The property order or the cssText string format caused
the `left: 280px` to not be applied correctly.

Instead, the browser created an `inset` shorthand with wrong values.

═══════════════════════════════════════════════════════════════════

THE FIX

Changed from:
```javascript
mainContent.style.cssText = 'position: absolute !important; left: 280px ...';
```

To:
```javascript
mainContent.style.position = 'absolute';
mainContent.style.left = '280px';  // ← CRITICAL!
mainContent.style.right = '0';
mainContent.style.top = '0';
mainContent.style.bottom = '0';
// ... etc
```

Setting each property individually ensures they're applied correctly.
