HOW TO USE:

1. Click "+ Options" button (bottom of chat input)

2. Click "🎨 Generate Image"
   → Input border turns GREEN
   → Notification appears: "🎨 Image Mode Active!"
   → Placeholder changes to: "Describe the image you want to generate..."

3. Type your image description:
   "a cozy fireplace with Santa and Mrs. Claus drinking hot cocoa"

4. Click Send

5. Image appears in chat! ✅
   → High quality 1024x1024 image
   → Click to open full size
   → Download button included

6. Image mode automatically turns OFF
   → Back to normal chat
