WHEN USER ENTERS CODE:
┌────────────────────────────────┐
│ 1. Check if code exists         │
│ 2. Check if code is active      │
│ 3. Check code type:             │
│    ├─ Single-use?               │
│    │  └─ Check times_used == 0  │
│    └─ Multi-use?                │
│       └─ Check times_used < max │
│ 4. Validate plan matches        │
│ 5. If valid, allow redemption   │
└────────────────────────────────┘

WHEN USER REDEEMS CODE:
┌────────────────────────────────┐
│ 1. Update user subscription     │
│ 2. Save code to user account    │
│ 3. Increment times_used         │
│ 4. Check if should deactivate:  │
│    ├─ Single-use?               │
│    │  └─ Set is_active = 0      │
│    └─ Multi-use?                │
│       └─ If times_used >= max   │
│          └─ Set is_active = 0   │
└────────────────────────────────┘
