Python Example

import requests

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://ai-team.skillsoul.store/api"

# Send message to Luna
response = requests.post(
    f"{BASE_URL}/chat",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "agent": "Luna",
        "message": "Analyze this data...",
        "context": {}
    }
)

result = response.json()
print(result['response'])

JavaScript (Browser) Example

const apiKey = 'YOUR_API_KEY';
const baseUrl = 'https://ai-team.skillsoul.store/api';

// Send message to Sage
fetch(`${baseUrl}/chat`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    agent: 'Sage',
    message: 'Write a blog post about...',
    context: {}
  })
})
.then(response => response.json())
.then(data => console.log(data.response))
.catch(error => console.error('Error:', error));

Node.js Example

const axios = require('axios');

const apiKey = 'YOUR_API_KEY';
const baseUrl = 'https://ai-team.skillsoul.store/api';

async function sendMessage() {
  try {
    const response = await axios.post(`${baseUrl}/chat`, {
      agent: 'Nova',
      message: 'Debug this code...',
      context: {}
    }, {
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Content-Type': 'application/json'
      }
    });
    
    console.log(response.data.response);
  } catch (error) {
    console.error('Error:', error);
  }
}

sendMessage();

⚡ Zapier Integration Guide

📋 Quick Setup

  1. Copy your API Key from the section above
  2. In Zapier: Create a new Zap
  3. Choose a trigger (e.g., "New Email in Gmail")
  4. Add an action: Search for "Webhooks by Zapier"
  5. Select: POST request
  6. URL: https://ai-team.skillsoul.store/api/automate/chat

⚙️ Request Configuration

Headers:

{
  "X-API-Key": "YOUR_API_KEY_HERE",
  "Content-Type": "application/json"
}

Request Body (JSON):

{
  "message": "Analyze this email: {EMAIL_BODY}",
  "agent": "Luna"
}
