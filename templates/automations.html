🚀 Quick Start

1. Create an API Key

Click "Create New API Key" above to generate your authentication token.

2. Make Your First Request

Use this example to chat with Luna:

curl -X POST https://ai-team-q84h.onrender.com/api/automate/chat \ -H "Content-Type: application/json" \ -H "X-API-Key: YOUR_API_KEY" \ -d '{ "message": "Analyze the latest AI trends", "agent": "Luna" }'

3. Get the Response

You'll receive a JSON response:

{ "success": true, "response": "Here are the key AI trends...", "agent": "Luna", "word_count": 150 }

📚 Code Examples

Python

import requests api_key = "YOUR_API_KEY" url = "https://ai-team-q84h.onrender.com/api/automate/chat" response = requests.post(url, headers={"X-API-Key": api_key}, json={ "message": "Help me plan my week", "agent": "Mila" } ) result = response.json() print(result['response'])

JavaScript / Node.js

const apiKey = "YOUR_API_KEY"; const url = "https://ai-team-q84h.onrender.com/api/automate/chat"; const response = await fetch(url, { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-API-Key': apiKey }, body: JSON.stringify({ message: "Write a blog post about AI", agent: "Sage" }) }); const data = await response.json(); console.log(data.response);

PHP

$apiKey = "YOUR_API_KEY"; $url = "https://ai-team-q84h.onrender.com/api/automate/chat"; $data = array( "message" => "Analyze this code for bugs", "agent" => "Nova" ); $options = array( 'http' => array( 'method' => 'POST', 'header' => "Content-Type: application/json\r\n" . "X-API-Key: $apiKey\r\n", 'content' => json_encode($data) ) ); $context = stream_context_create($options); $result = file_get_contents($url, false, $context); $response = json_decode($result, true); echo $response['response'];

📖 API Reference

Endpoint

POST https://ai-team-q84h.onrender.com/api/automate/chat

Headers

Header Required Description
X-API-Key Yes Your API key for authentication
Content-Type Yes Must be application/json

Request Body

Field Type Required Description
message string Yes Your question or prompt for the agent
agent string No Agent name (Luna, Mila, Sage, Ember, Sol, Nova, Theo). Default: Ember

Response

{ "success": true, "response": "The AI agent's response", "agent": "Luna", "word_count": 150, "token_warning": false }
