Send a Message to an AI Agent

curl -X POST https://ai-team.skillsoul.store/api/chat \
 -H "Authorization: Bearer YOUR_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "agent": "Luna",
 "message": "Analyze this quarterly sales data...",
 "context": {}
 }'

Python Example

import requests

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://ai-team.skillsoul.store/api"

# Send message to Luna
response = requests.post(
 f"{BASE_URL}/chat",
 headers={"Authorization": f"Bearer {API_KEY}"},
 json={
 "agent": "Luna",
 "message": "Analyze this data...",
 "context": {}
 }
)

result = response.json()
print(result['response'])

JavaScript (Browser) Example

const apiKey = 'YOUR_API_KEY';
const baseUrl = 'https://ai-team.skillsoul.store/api';

// Send message to Sage
fetch(`${baseUrl}/chat`, {
 method: 'POST',
 headers: {
 'Authorization': `Bearer ${apiKey}`,
 'Content-Type': 'application/json'
 },
 body: JSON.stringify({
 agent: 'Sage',
 message: 'Write a blog post about...',
 context: {}
 })
})
.then(response => response.json())
.then(data => console.log(data.response))
.catch(error => console.error('Error:', error));

Node.js Example

const axios = require('axios');

const apiKey = 'YOUR_API_KEY';
const baseUrl = 'https://ai-team.skillsoul.store/api';

async function sendMessage() {
 try {
 const response = await axios.post(`${baseUrl}/chat`, {
 agent: 'Nova',
 message: 'Debug this code...',
 context: {}
 }, {
 headers: {
 'Authorization': `Bearer ${apiKey}`,
 'Content-Type': 'application/json'
 }
 });

 console.log(response.data.response);
 } catch (error) {
 console.error('Error:', error);
 }
}

sendMessage();

Webhook Management

Webhooks notify your external services (like Make.com or Zapier) when events occur in AI Team.

Loading webhooks...

Available Events:

  • message.completed - When an AI agent responds to a message
  • image.generated - When an AI image is created
  • agent.response - Any agent response event

Webhook Payload Example:

{
 "event": "message.completed",
 "agent": "Luna",
 "message": "Analyze this data...",

 "timestamp": "2025-11-29T12:00:00Z",
 "user_id": 1
